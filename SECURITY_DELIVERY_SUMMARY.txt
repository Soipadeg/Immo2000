🔐 FONCTIONNALITÉS IMPLÉMENTÉES

1. DOUBLE AUTHENTIFICATION (2FA)
   ✅ TOTP (Time-based One-Time Password) via pyotp
   ✅ QR codes générés automatiquement
   ✅ 10 codes de secours par utilisateur
   ✅ Vérification lors de la connexion
   ✅ Interface utilisateur complète

   Routes:
   • GET  /api/v1/security/2fa/setup       → Générer secret + QR
   • POST /api/v1/security/2fa/setup       → Activer 2FA
   • POST /api/v1/security/2fa/disable     → Désactiver 2FA
   • POST /api/v1/security/2fa/verify      → Vérification login

2. VÉRIFICATION D'IDENTITÉ
   ✅ Support Yousign (France - recommandé)
   ✅ Support Veriff (International)
   ✅ Documents: Passport, ID Card, Driving License
   ✅ Validité 5 années
   ✅ Webhooks de callback
   ✅ Historique complet

   Routes:
   • POST /api/v1/security/identity/start      → Démarrer vérif
   • POST /api/v1/security/identity/callback   → Webhook fournisseur

3. CONFORMITÉ RGPD
   ✅ Droit d'accès aux données (export JSON/CSV)
   ✅ Droit à l'oubli (suppression compte avec délai 30j)
   ✅ Droit de rectification (via PATCH existant)
   ✅ Droit à la portabilité (export structure)
   ✅ Processus de confirmation par email
   ✅ Anonymisation progressive

   Routes:
   • GET  /api/v1/security/rgpd/status                      → Statut demandes
   • POST /api/v1/security/rgpd/export-data                 → Demander export
   • POST /api/v1/security/rgpd/delete-account              → Demander suppression
   • POST /api/v1/security/rgpd/confirm-deletion/<token>    → Confirmer

4. AUDIT & LOGGING
   ✅ Immutable audit trail de toutes actions sensibles
   ✅ 20+ types d'actions tracées (LOGIN, DELETE_DATA, etc.)
   ✅ Traçabilité: utilisateur, IP, action, ressource, risk level
   ✅ Décorateur automatique @audit_decorator
   ✅ Stockage BD + fichiers
   ✅ Rétention 7 ans (conformité légale)

   Actions Tracées:
   • Authentication: LOGIN, LOGOUT, REGISTER, FAILED_2FA
   • Data: DELETE_DATA, EXPORT_DATA, UPDATE_PROFILE
   • Transactions: CREATE_TRANSACTION, SIGN_DOCUMENT
   • Security: ENABLE_2FA, DISABLE_2FA, COMPLETE_IDENTITY_VERIFICATION
   • Admin: DELETE_ACCOUNT, LOCK_ACCOUNT

5. DÉTECTION DES MENACES
   ✅ Détection tentatives connexion échouées (5+ en 24h)
   ✅ Alertes IPs inhabituelles
   ✅ Détection actions rapides suspectes (10+ en 1min)
   ✅ Niveaux sévérité: low, medium, high, critical
   ✅ Actions automatiques: blocage IP, verrouillage compte

   Table: security_events

6. PROTECTION XSS
   ✅ Sanitization automatique via bleach
   ✅ Suppression tags dangereux (<script>, onclick, etc.)
   ✅ Whitelist des tags sûrs (p, a, strong, em, etc.)
   ✅ Décorateur @XSSProtection.clean_decorator
   ✅ Fonction clean_input() pour validation

   Usage: XSSProtection.clean_input(user_input)

7. RATE LIMITING
   ✅ Par IP (RateLimiter class)
   ✅ Défaut: 10 login/minute, 100 API/heure
   ✅ HTTP 429 si dépassé
   ✅ Intégration Flask-Limiter optionnelle

   Configuré pour:
   • Login: 5 tentatives/minute
   • API: 50 requêtes/heure
   • RGPD: 1 demande/jour

8. HTTP SECURITY HEADERS
   ✅ HSTS (Strict-Transport-Security: 31536000s)
   ✅ CSP (Content-Security-Policy)
   ✅ X-Frame-Options: DENY (clickjacking)
   ✅ X-Content-Type-Options: nosniff (MIME sniffing)
   ✅ Via Flask-Talisman

═══════════════════════════════════════════════════════════════════════════════
🗄️ BASE DE DONNÉES - 5 NOUVELLES TABLES
═══════════════════════════════════════════════════════════════════════════════

1. security_profiles (Profil de sécurité utilisateur)
   • 2FA: secret_2fa, is_2fa_enabled, backup_codes
   • Vérification: identite_verifiee, verification_id, expires
   • Sessions: trusted_devices, active_sessions
   • Sécurité: failed_login_attempts, account_locked_until
   • Alertes: last_security_alert, security_alert_count

2. audit_logs (Journal d'audit immutable)
   • action, action_category, resource_type, resource_id
   • status (success/failed), risk_level (low/medium/high/critical)
   • ip_address, user_agent, country_code
   • timestamp (indexé) - Rétention 7 ans

3. rgpd_requests (Demandes RGPD)
   • request_type (data_export/delete_account/anonymize)
   • status (pending/confirmed/processing/completed)
   • confirmation_token, confirmation_expires
   • data_url, result (JSON)
   • timestamps: requested_at, confirmed_at, completed_at

4. identity_verification_logs (Historique vérifications)
   • provider (yousign/veriff), verification_id
   • first_name, last_name, document_type
   • status, verification_data (JSON)
   • started_at, completed_at, expires_at

5. security_events (Détection menaces)
   • event_type (failed_login/unusual_ip/rapid_actions)
   • severity (low/medium/high/critical)
   • ip_address, country_code
   • action_taken (none/alert_user/lock_account)
   • timestamp
