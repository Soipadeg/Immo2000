## **🔹 3. Recherche du bien**
- [ ] **Activer les alertes** sur immo2000 pour vos critères
- [ ] **Consulter les annonces** quotidiennement
- [ ] **Visiter les biens** correspondants (minimum 3-5 visites)
- [ ] **Comparer les biens** avec notre outil de comparaison
- [ ] **Vérifier les prix au m²** dans le quartier

---
## **🔹 4. Visite du bien**
### **À faire avant la visite**
- [ ] Prendre rendez-vous via le **calendrier en ligne**
- [ ] Vérifier l’**adresse exacte** et les accès
- [ ] Préparer une **liste de questions** (voir ci-dessous)
- [ ] Emporter un **mètre ruban** et un **carnet de notes**

### **Questions à poser pendant la visite**
- [ ] Pourquoi le vendeur quitte-t-il le bien ?
- [ ] Y a-t-il des **travaux prévus** dans la copropriété ?
- [ ] Quel est le **montant des charges** (pour les copropriétés) ?
- [ ] Le bien a-t-il des **problèmes d’humidité/isolations** ?
- [ ] Quelle est la **classe énergétique (DPE)** ?
- [ ] Y a-t-il des **nuisances sonores** (voisins, rue bruyante) ?
- [ ] Quel est l’**état de la toiture/charpente** ?
- [ ] Y a-t-il des **servitudes** (droit de passage, etc.) ?

### **À vérifier pendant la visite**
- [ ] **État général** :
  - [ ] Peinture, sols, murs
  - [ ] Plomberie (robinets, évacuations)
  - [ ] Électricité (interrupteurs, prises)
  - [ ] Chauffage/Climatisation
- [ ] **Luminosité** :
  - [ ] Orientation des pièces (sud = meilleur)
  - [ ] Taille des fenêtres
- [ ] **Isolation** :
  - [ ] Simple/double vitrage
  - [ ] Isolation des murs/toiture
- [ ] **Sécurité** :
  - [ ] Porte d’entrée (blindée ?)
  - [ ] Serrures des fenêtres
  - [ ] Détecteurs de fumée
- [ ] **Extérieurs** :
  - [ ] État de la façade
  - [ ] Toiture (tuiles, gouttières)
  - [ ] Balcon/terrasse (état, sécurité)
  - [ ] Jardin (entretien, clôture)

---
## **🔹 5. Faire une offre**
- [ ] **Utiliser notre modèle d’offre** ([Lien])
- [ ] **Définir le prix proposé** (négociation possible)
- [ ] **Inclure des conditions suspensives** :
  - [ ] Obtention d’un prêt bancaire
  - [ ] Vente de mon bien actuel (si applicable)
- [ ] **Définir un délai de réponse** (ex : 5 jours)
- [ ] **Envoyer l’offre** au vendeur via la plateforme
- [ ] **Attendre la réponse** (acceptation, refus, contre-proposition)

---
## **🔹 6. Signature du compromis**
- [ ] **Relire attentivement** le compromis (clauses suspensives, délais)
- [ ] **Vérifier les informations** (prix, description du bien, coordonnées)
- [ ] **Consulter un notaire** si besoin (nous pouvons vous en recommander un)
- [ ] **Signer électroniquement** via Yousign
- [ ] **Recevoir le compromis signé** par email

---
## **🔹 7. Finalisation de l’achat**
- [ ] **Transmettre le compromis à la banque** (pour finaliser le prêt)
- [ ] **Attendre l’accord définitif** de la banque
- [ ] **Vérifier les diagnostics** (DPE, ERP, électrique, gaz, plomb, termites)
- [ ] **Préparer les documents pour le notaire** :
  - [ ] Pièce d’identité
  - [ ] Justificatif de domicile
  - [ ] Preuve de financement (accord de prêt)
  - [ ] Compromis de vente signé
- [ ] **Prendre rendez-vous chez le notaire**
- [ ] **Signer l’acte authentique** (dernière étape !)
- [ ] **Recevoir les clés** et emménager !

---
## **🔹 8. Après l’achat**
- [ ] **Changer les serrures** (pour des raisons de sécurité)
- [ ] **Mettre à jour les contrats** (électricité, gaz, eau, internet)
- [ ] **Souscrire une assurance habitation**
- [ ] **Déclarer votre nouvelle adresse** (La Poste, CAF, impôts, etc.)
- [ ] **Faire un état des lieux d’entrée** (si location précédente)

---
> **💡 Conseil** : Gardez une **copie de tous les documents** (compromis, acte de vente, diagnostics) dans un dossier sécurisé.
