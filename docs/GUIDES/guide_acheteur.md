## 📌 **Étape 2 : Créer votre annonce sur immo2000 **
1. **Connectez-vous** à votre compte sur [immo2000.fr](https://immo2000.fr).
2. Allez dans **‘Mes biens’ > ‘Nouveau bien’**.
3. **Remplissez les informations** :
   - **Adresse** : Précisez la rue, le code postal, et la ville.
   - **Caractéristiques** : Surface, nombre de pièces, type de bien, année de construction.
   - **Prix** : Utilisez notre **outil d’estimation** pour un prix réaliste.
   - **Photos** : Ajoutez **au moins 5 photos** (10 maximum).
   - **Description** : Copiez-collez votre texte préparé (voir étape 1).
4. **Validez** : Votre annonce sera **en ligne sous 24h** après vérification par notre équipe.

> 💡 **Astuce** : Activez l’option **"Alertes prix"** pour être notifié si un bien similaire est vendu à un prix inférieur dans votre quartier.

## 📌 **Étape 3 : Gérer les visites**
### ✅ **Planifier les visites**
- Les acheteurs **réservent un créneau** via votre calendrier en ligne.
- Vous recevez une **notification par email/SMS** avec :
  - Le nom et prénom de l’acheteur.
  - Son numéro de téléphone.
  - L’heure et la date de la visite.
- **Répondez sous 24h** pour confirmer ou proposer un autre horaire.

### ✅ **Préparer la visite**
- **Checklist avant la visite** :
  - [ ] Aérez les pièces 30 min avant.
  - [ ] Allumez toutes les lumières.
  - [ ] Préparez les documents (DPE, diagnostic électrique, etc.).
  - [ ] Prévoyez 1h pour la visite (même pour un petit bien).
- **Pendant la visite** :
  - **Soyez transparent** : Mentionnez les défauts (ex : "La salle de bain sera à rénover").
  - **Mettez en avant les atouts** : "Cette cuisine a été refaite il y a 2 ans."
  - **Répondez aux questions** : Si vous ne savez pas, dites-le (ex : "Je ne connais pas l’état de la toiture, mais le diagnostic le précisera").

### ✅ **Après la visite**
- **Envoyez un message** via la plateforme pour :
  - Remercier l’acheteur.
  - Lui demander son **feedback** (ex : "Qu’avez-vous pensé du bien ?").
  - Lui proposer de **répondre à ses questions** supplémentaires.

## 📌 **Étape 4 : Recevoir et négocier les offres**
### ✅ **Analyser les offres**
- Chaque offre est **centralisée dans votre espace** "Mes offres".
- **Critères à vérifier** :
  - **Prix proposé** : Comparez avec votre prix de vente.
  - **Conditions suspensives** : Prêt bancaire ? Vente d’un autre bien ?
  - **Délai de réponse** : L’acheteur a-t-il mis une limite ?
  - **Financement** : Prêt pré-accordé ou fonds propres ?

### ✅ **Outils pour vous aider**
| Outil | Description |
|-------|-------------|
| **Comparateur d’offres** | Classe les offres par prix, délai, et conditions. |
| **Simulateur de négociation** | Estime si une offre est **raisonnable** ou non. |
| **Historique des ventes** | Voir les prix des biens similaires **vendus récemment** dans votre quartier. |

### ✅ **Répondre à une offre**
- **Accepter** : L’acheteur est notifié automatiquement. Un **compromis de vente** est généré.
- **Refuser** : L’acheteur est informé, et peut faire une **nouvelle offre**.
- **Contre-proposition** : Proposez un prix ou des conditions différentes.

> ⚠️ **Attention** : Une fois le compromis signé, vous êtes **engagé** (sauf condition suspensive non remplie).

---
## 📌 **Étape 5 : Signer le compromis de vente**
1. **Génération du compromis** :
   - Notre plateforme **génère automatiquement** le document avec :
     - Les informations du bien.
     - Le prix et les conditions négociées.
     - Les coordonnées de l’acheteur et du vendeur.
2. **Vérification** :
   - Relisez **attentivement** le document (notamment les clauses suspensives).
   - Si besoin, **consultez un notaire** (nous pouvons vous en recommander un).
3. **Signature électronique** :
   - Vous et l’acheteur signez via **Yousign** (valeur légale garantie).
   - Le compromis est **envoyé automatiquement au notaire**.

---
## 📌 **Étape 6 : Finaliser la vente**
### ✅ **Suivre les étapes légales**
- **Délai de rétractation** : L’acheteur a **10 jours** pour se rétracter.
- **Condition suspensive de prêt** : Si l’acheteur a besoin d’un prêt, la vente est **suspendue** jusqu’à l’obtention du financement.
- **Signature chez le notaire** :
  - Le notaire **vérifie tous les documents** (DPE, diagnostics, etc.).
  - Vous recevez le **paiement** (le notaire transfère les fonds sur votre compte).

### ✅ **Recevoir le paiement**
- Le notaire **retient la commission de 1,5%** et vous verse le reste.
- **Délai** : Sous 48h après la signature définitive.
