# 🏡 **Acheter en Direct avec immo2000 **
*Un guide étape par étape pour acheter un bien **sans agence**, en toute transparence.*

---

## 🎯 **Pourquoi acheter en direct ?**
   **Critère**               | **Avec une agence**       | **Avec immo2000 **  | **Avantage**              |
 |--------------------------|---------------------------|--------------------------|---------------------------|
 | Frais d’agence           | 0% (mais inclus dans le prix) | **0%** (vous ne payez rien) | **Économie immédiate** |
 | Transparence             | Prix parfois gonflés     | **Prix réels** (pas de marge agence) | **Meilleur rapport qualité-prix** |
 | Négociation              | Intermédiaire obligatoire | **Direct avec le vendeur** | **Plus de flexibilité** |
 | Accès aux annonces       | Limité aux biens en agence | **Tous les biens** (y compris ceux en vente directe) | **Plus de choix** |

> 💡 **Exemple** : Pour un achat à **300 000 €**, vous économisez **jusqu’à 6 000 €** (2% de frais d’agence évités).

---

## 📌 **Étape 1 : Définir votre budget**
### ✅ **Calculer votre capacité d’emprunt**
- Utilisez notre **simulateur de prêt** : [Lien](https://immo2000.fr/simulateur-pret).
- **Règle des 35%** : Vos mensualités ne doivent pas dépasser **35% de vos revenus**.
- **Exemple** :
  - Revenus mensuels : 3 000 € → Mensualité max : **1 050 €**.
  - Avec un taux à **3,5% sur 20 ans**, vous pouvez emprunter **~200 000 €**.

### ✅ **Prévoir les frais annexes**
 | **Frais**                | **Coût estimé**       | **Détails**                          |
 |--------------------------|-----------------------|--------------------------------------|
 | Frais de notaire         | 2% à 8% du prix       | Variable selon l’ancienneté du bien. |
 | Frais de dossier bancaire| 0% à 1% du prêt        | Négociable avec votre banque.       |
 | Diagnostic immobilier    | 300 € à 800 €         | À la charge du vendeur (sauf DPE).   |
 | **Total**               | **~3% à 10% du prix** |                                      |

> ⚠️ **Exemple** : Pour un bien à **300 000 €**, prévoyez **6 000 € à 30 000 €** de frais supplémentaires.

---
## 📌 **Étape 2 : Rechercher un bien**
### ✅ **Utiliser les filtres avancés**
- **Localisation** : Ville, quartier, code postal.
- **Caractéristiques** :
  - Type de bien (appartement, maison, terrain).
  - Surface (min/max).
  - Nombre de pièces.
  - Prix (min/max).
  - **DPE** (classe énergétique : A à G).
- **Options** :
  - [ ] Avec balcon/terrasse.
  - [ ] Avec parking.
  - [ ] Proche des transports.

### ✅ **Activer les alertes**
- **Comment** :
  1. Créez un compte sur [immo2000.fr](https://immo2000.fr).
  2. Allez dans **‘Mes alertes’**.
  3. Définissez vos critères (ex : "Appartement à Paris, 2 pièces, < 300 000 €").
  4. Recevez un **email/SMS** dès qu’un nouveau bien correspond à vos critères.

### ✅ **Comparer les biens**
- Utilisez notre **outil de comparaison** pour :
  - Voir les biens **côte à côte**.
  - Comparer les **prix au m²**.
  - Vérifier les **DPE et diagnostics**.

---
## 📌 **Étape 3 : Organiser une visite**
### ✅ **Prendre rendez-vous**
- Cliquez sur **"Demander une visite"** sur l’annonce.
- Sélectionnez un **créneau disponible** dans le calendrier du vendeur.
- **Confirmez** : Vous recevrez un **email/SMS de rappel** 24h avant.

### ✅ **Préparer la visite**
- **Checklist** :
  - [ ] Vérifiez l’**adresse exacte** (certains biens sont en copropriété).
  - [ ] Préparez une **liste de questions** (ex : "Quels travaux ont été faits ?").
  - [ ] Emportez un **mètre ruban** (pour vérifier les surfaces).
  - [ ] Prenez des **notes et photos** (si autorisé).
- **Questions à poser** :
  - "Pourquoi le vendeur quitte-t-il le bien ?"
  - "Y a-t-il des **travaux prévus** dans la copropriété ?"
  - "Quel est le **montant des charges** ?"
  - "Le bien a-t-il des **problèmes d’humidité/isolations** ?"

### ✅ **Pendant la visite**
- **Observez** :
  - L’état général (peinture, sol, plomberie).
  - La luminosité (visitez à différentes heures si possible).
  - Le voisinage (bruyant ? sécurisé ?).
- **Testez** :
  - Ouvrez les robinets (pression de l’eau).
  - Allumez les lumières et les appareils électriques.
  - Vérifiez l’**isolation thermique** (fenêtres, murs).

---
## 📌 **Étape 4 : Faire une offre**
### ✅ **Utiliser notre modèle d’offre**
1. Cliquez sur **"Faire une offre"** sur l’annonce.
2. Remplissez le formulaire :
   - **Prix proposé** (vous pouvez négocier).
   - **Conditions suspensives** :
     - [x] Obtention d’un prêt bancaire (si applicable).
     - [ ] Vente de mon bien actuel.
   - **Délai de réponse** (ex : 5 jours).
3. **Validez** : Votre offre est envoyée au vendeur.

### ✅ **Négocier le prix**
- **Outils pour vous aider** :
  - **Historique des ventes** : Voir les prix des biens similaires **vendus récemment**.
  - **Indicateur de marché** : Notre algorithme vous dit si le prix est **raisonnable** ou non.
- **Exemple de négociation** :
  - Prix demandé : 300 000 €.
  - Prix moyen du quartier : 280 000 €.
  - **Proposition** : 290 000 € (avec justification : "Les biens similaires se vendent à 280-290k€").

---
## 📌 **Étape 5 : Signer le compromis de vente**
1. **Réception de l’offre acceptée** :
   - Le vendeur a **accepté votre offre** → Un **compromis de vente** est généré.
2. **Vérification du compromis** :
   - Lisez **attentivement** les clauses (notamment les conditions suspensives).
   - Si besoin, **consultez un notaire** (nous pouvons vous en recommander un).
3. **Signature électronique** :
   - Vous et le vendeur signez via **Yousign** (valeur légale garantie).
   - Le compromis est **envoyé automatiquement au notaire**.

> ⚠️ **Délai de rétractation** : Vous avez **10 jours** pour vous rétracter **sans justification**.

---
## 📌 **Étape 6 : Finaliser l’achat**
### ✅ **Obtenir un prêt (si applicable)**
- **Transmettez le compromis** à votre banque.
- **Délai moyen** : 1 à 2 mois pour obtenir une réponse.
- **Si refus** : La vente est **annulée** (grâce à la condition suspensive).

### ✅ **Signer chez le notaire**
- Le notaire **vérifie tous les documents** :
  - DPE, diagnostics, titre de propriété.
  - Absence de servitudes ou de dettes sur le bien.
- **Paiement** :
  - Vous payez le **prix du bien + frais de notaire**.
  - Le vendeur reçoit le **prix de vente - 1,5% de commission**.
