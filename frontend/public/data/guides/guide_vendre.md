# 📖 Guide Complet : Vendre en Direct avec immo2000

*Un guide étape par étape pour vendre votre bien **sans agence**, en toute sécurité et à moindre coût.*

---

## 🎯 Pourquoi vendre en direct ?

| Critère | Avec une agence | Avec immo2000 | Économie |
|---------|-----------------|----------------|----------|
| Commission | 7% à 20% du prix de vente | **1,5%** | **Jusqu'à 18 500 €** |
| Contrôle sur la vente | Limité (l'agence décide) | **Total** | Vous décidez |
| Flexibilité | Horaires imposés | **Libre** (vous gérez) | Votre emploi du temps |
| Transparence | Opacité sur les offres | **Toutes les offres visibles** | Meilleure maîtrise |

> ⚠️ **Exemple concret** : Pour un apartement vendu **300 000 €**, vous économisez **18 500 €** (20% - 1,5% = 18,5%).

## 📌 Étape 1 : Préparer votre bien

### ✅ Nettoyer et désencombrer

**Objectif** : Permettre aux acheteurs de **se projeter** dans votre bien.

- **Dépoussiérez** toutes les surfaces
- **Rangez** les objets personnels (photos, vêtements)
- **Désencombrez** les placards (les acheteurs les ouvrent !)
- **Aérez** les pièces pour une meilleure atmosphère

### ✅ Faire des réparations mineures

Avant de mettre en ligne votre annonce :

- Réparez les fuites d'eau
- Remplacez les ampoules grillées
- Repeindre si nécessaire (tons neutres)
- Nettoyez les vitres et les carreaux

> 💡 **Astuce** : Les petites réparations coûtent peu mais augmentent considérablement l'attrait du bien.

## 💰 Étape 2 : Estimer le prix

### ✅ Utiliser un outil d'estimation

Rendez-vous sur la page **[matching](/matching.html)** et utilisez notre **outil d'estimation automatique**.

L'outil prend en compte :

- **Localisation** : Quartier, proximité transports
- **Surface** : Pièces, étage, exposition
- **État du bien** : Rénovation, diagnostics
- **Marché local** : Prix moyens dans votre secteur

### ✅ Valider le prix

- Comparez avec **3 à 5 biens similaires** vendus récemment
- Considérez votre urgence de vendre (délai court = prix réduit)
- Fixez un prix réaliste (trop bas = regret, trop haut = pas d'acheteurs)

> 📊 **Conseil** : Laissez une marge de 5-10% pour les négociations.

---

## 📸 Étape 3 : Créer votre annonce

### ✅ Rédiger la description

Écrivez une description **claire, attrayante et honnête** :

- Longueur : **150 à 300 mots**
- Toné : Positif, sans exagération
- Soyez factuel (pas de promesses vides)
- Mettez en avant les points forts : vue, luminosité, calme

**Exemple de structure** :

> "Charmant appartement 3 pièces dans un immeuble haussmannien, 8ème étage avec ascenseur. Entrée, séjour lumineux, 2 chambres, cuisine aménagée, salle de bain. Bien entretenu, diagnostics neufs. Proche métro, commerces, écoles. Idéal famille ou couple."

### ✅ Ajouter des photos

- **Minimum 5 photos**, **maximum 20**
- **Qualité** : Lumière naturelle, images nettes
- **Angles** : Chaque pièce de face, coin, détails
- **Ordre** : Entrée → Séjour → Chambres → Cuisine → Salle de bain

> 📸 **Astuce** : Les photos claires augmentent les visites de 30% !

### ✅ Remplir les informations

1. Connectez-vous à **[votre compte](/dashboard.html)**
2. Allez à **"Mes biens" > "Ajouter un bien"**
3. Remplissez :
   - Adresse complète
   - Type de bien (appartement, maison, etc.)
   - Surface totale et par pièce
   - Nombre de pièces/chambres
   - Prix demandé
   - État du bien (excellent, bon, à rénover)
4. Uploadez les photos
5. Ajoutez la description
6. **Validez** (votre annonce sera en ligne sous 24h)

## 📅 Étape 4 : Gérer les visites

### ✅ Planifier les visites

Les acheteurs **réservent un créneau** via votre calendrier en ligne.

Vous recevez une **notification email/SMS** avec :

- Nom et prénom de l'acheteur
- Son numéro de téléphone
- Date et heure de la visite
- Son profil (acheteur sérieux, budget, etc.)

Répondez sous **24h** pour confirmer ou proposer un autre horaire.

### ✅ Préparer la visite

**Checklist avant la visite** :

- [ ] Aérez les pièces 30 min avant
- [ ] Allumez toutes les lumières
- [ ] Préparez les documents (DPE, diagnostic électrique, etc.)
- [ ] Enlevez les animaux domestiques (allergies)
- [ ] Limitez les odeurs de cuisine
- [ ] Rangez rapidement les affaires
- [ ] Prévoyez 1h minimum pour la visite

### ✅ Pendant la visite

- Soyez **courtois et discret** (laissez l'acheteur explorer)
- **Répondez honnêtement** à ses questions
- Ne critiquez jamais le bien
- Montrez les documents (diagnostics, factures chauffage)
- Proposez du café/thé (touche personnelle)
- Échangez vos coordonnées

---

## 🤝 Étape 5 : Traiter les offres

### ✅ Recevoir une offre

L'acheteur fait une **offre d'achat** avec :

- Prix proposé
- Délais de signature
- Conditions (inspection, financement)
- Équipements inclus/exclus

### ✅ Négocier

Vous pouvez :

- **Accepter** l'offre (en ligne immédiatement)
- **Refuser** (réponse courtoise recommandée)
- **Contreproposer** (prix, délai, conditions)

> 💡 **Conseil** : Soyez réactif ! Les acheteurs qui attendent se découragent.

### ✅ Signer

Une fois d'accord :

1. Signalez l'offre acceptée dans votre compte
2. Contactez un **notaire** (immo2000 peut vous recommander)
3. Signez le **compromis de vente** (engagement mutuel)
4. Attendez ~4 semaines
5. Signez l'**acte de vente** définitif
6. Recevez l'argent sur votre compte ! 🎉
